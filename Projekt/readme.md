# Smart Room Comfort System 2026

Projekt inteligentnego systemu monitorowania i regulacji komfortu środowiskowego w salach dydaktycznych lub biurowych.

## Opis projektu

System służy do monitorowania temperatury, wilgotności, stężenia CO2, natężenia światła, poziomu hałasu oraz obecności osób w pomieszczeniu. Na podstawie danych z czujników system analizuje komfort środowiskowy i może sterować wentylacją, ogrzewaniem, klimatyzacją lub oświetleniem.

## Funkcje

- odczyt parametrów środowiskowych,
- wysyłanie danych z ESP32 do backendu,
- analiza progów komfortu,
- tryb ECO dla pustych sal,
- alerty dla administratora,
- historia pomiarów,
- dokumentacja i diagramy UML.

## Technologie

- ESP32
- Python
- FastAPI
- REST API
- JSON
- SQLite/PostgreSQL
- GitHub/GitLab

## Struktura projektu

- `/docs` - dokumentacja, diagramy UML i sprawozdanie

- `/tests` - testy jednostkowe
